# Review 檢核表

使用時機：
- 子 AI 送 PR 前自我檢查，結果貼在 PR 說明。
- 主 AI review 時逐項確認。

規範全文：`.github/copilot-instructions.md`。

## A. 範圍與流程
- [ ] 修改規劃已經主 AI 同意
- [ ] 只改自己那一門課；動到共用檔的部分已事先說明並獲同意
- [ ] 共用檔只有「新增」，沒有改壞其他課程
- [ ] 一門課一個 PR，標題寫成「課程名稱：做了什麼」

## B. 登記（新課程或改名時）
- [ ] `site.js` LESSONS 欄位齊全，放在正確級別
- [ ] 首頁卡片已加，級別、emoji、標題都正確；有人偶導讀的卡片加了 ▶ 標記
- [ ] 首頁級別總時間已更新

## C. 內容
- [ ] 開頭講清楚「學完你會」
- [ ] 每段先講結論；專有名詞有白話解釋
- [ ] 提示詞完整、可以直接複製，要自己填的地方用【】標示
- [ ] 示意圖的 figcaption 註明是示意圖
- [ ] 有常見問題和自我檢核（簡報型、互動頁除外）
- [ ] 人偶導讀依 LEVEL1 → LEVEL2 → 精選 LEVEL3 的順序講

## D. 文字
- [ ] 繁體中文、台灣用語、全形標點
- [ ] 中英文、中文與數字之間有空格
- [ ] 沒有誇大；引用的數字註明出處或「個人經驗」

## E. 安全
- [ ] 全部是虛構資料
- [ ] 沒有內網 IP、主機名、帳密、Token、真實客戶或組織名稱

## F. 畫面與功能（要附實測結果）
- [ ] 電腦 1280px 正常
- [ ] 手機 390px 沒有水平捲動，文字沒被切掉
- [ ] 夜間主題可讀
- [ ] Console 除了 favicon 以外沒有錯誤
- [ ] 目錄錨點、上一課／下一課、複製鈕都正常
- [ ] 下載檔可以下載、可以解壓
- [ ] 暫存截圖已刪除，沒有 commit 進去

## G. 上版
- [ ] 使用者已說「通過」或「合併」
- [ ] 上版後正式網址回應 200，內容是新版
- [ ] 已通知「教材修改歷程」子 AI 新增紀錄
