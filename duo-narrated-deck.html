學習路線：由淺入深

  1. 入門（第 1–3 步，約 10 分）：看成果、懂原理、裝好 Skill。
  2. 核心（第 4–6 步，約 20 分）：認識 10 個步驟和 3 道審核關卡，學會審教案、審對話稿。
  3. 收尾（第 7–8 步，約 15 分）：產生語音、嵌入網頁、驗證後上線。

名詞小辭典：Skill = 寫給 AI 看的 SOP 說明書；TTS = 文字轉語音；錨點 = 人偶要走過去的那段畫面文字；LEVEL1／2／3 = 一頁的大標題／小標題／小標底下的細項。

第 1 步：先看成果

本站有兩課已經用這個 Skill 做好，打開後按右上角 ▶ 聽報告（或按 P）：

  • 〈NotebookLM 業務助理〉：29 頁，約 30 分。
  • 〈知識庫分享〉：17 頁，約 21 分，深講版。

你會看到 5 件事：

  1. 人偶走位：小貓先出發，機器人晚半秒跟上，走到正在講的重點旁邊。
  2. 泡泡：講話的那隻頭上有短句，另一隻轉頭看它。
  3. 打亮：講到的區塊變亮，其他地方稍微變暗。
  4. 字幕：畫面下方，標出是誰在講；講到成語會跳出白話小卡。
  5. 重點卡：每頁講完，跳出「一句話重點」。

播放列可勾「自動連播」（一路播完）、「字幕」、「人偶」，語速可切 1x／1.25x／1.5x。手機上人偶會隱藏，只留字幕。

重點：人偶不是裝飾。它帶著眼睛走，聽的人不會「聽到第三點，卻還在看第一點」。

第 2 步：它怎麼運作

整個 Skill 只有 3 支 Python 腳本，加一個播放器。資料這樣流：

  1. 原網頁 .html
  2. slides_text.py 列出每頁文字
  3. 對話稿（AI 寫、你審）
  4. gen_duo_audio.py 產生語音
  5. duo.json
  6. embed_duo.py 嵌回網頁
  7. 會自己講的 .html

比喻：像拍一支導覽影片。原網頁是場景，對話稿是劇本，語音是配音，播放器是導演，告訴演員什麼時候走到哪裡。

  • 語音用微軟 Edge 的免費 TTS（edge-tts）：小貓是「曉臻」，機器人是「雲哲」。
  • 語音直接包進 HTML，只有一個檔案，放上 GitHub Pages 就能用，不需要伺服器。
  • 大小約「每分鐘語音 0.42 MB」：30 分鐘約 12.6 MB。

第 5 步：擬教案──先懂教材，再寫稿

好的導讀不是把字唸出來，而是照教材的編寫思路帶人走。所以 AI 先用資深教育人員的角度寫教案，內容有 4 塊：

  1. 課程定位：聽眾、先備知識、總時長、上完能做到的 2～3 件事。
  2. 教學脈絡：分幾章、為什麼這樣排（例如引起動機 → 建立概念 → 實務經驗 → 動手應用）。
  3. 每頁表格：LEVEL1、3～4 個 LEVEL2、每個 LEVEL2 怎麼扣回 LEVEL1、深講時選哪個 LEVEL3 當代表。
  4. 教材調整建議：頁面結構不合時（LEVEL2 太多、太少、沒小標），提出怎麼改，你同意才動網頁。

第 6 步：寫對話稿

對話稿是純文字，一頁一個區塊。每一段先寫「角色｜錨點｜泡泡」，下一行寫要唸的台詞：

對話稿.txt（節錄）
【P3】重點：有文件不等於有知識，人人都在盲人摸象
貓｜我們遇到的問題｜為什麼查這麼久
為什麼問一個問題，常常要查半小時？
機｜=｜盲人摸象
因為人人都在盲人摸象，只摸到一部分，就以為懂了全部。這四張卡，是查很久的四個原因。
貓｜規模龐大｜第一個原因
第一個原因是什麼？
機｜Java 5,076 支｜五千多支程式
系統太大。光 Java 就五千零七十六支，選單功能一千三百多個。一個人看不完，只好每人顧一塊。
  • 錨點要從畫面上複製、只出現一次的字；= 表示跟上一段同位置；家 表示回角落。
  • 泡泡15 字以內；每段台詞 70 字以內，方便看字幕。
  • 重點是每頁講完跳出的「一句話重點」卡。

寫作 5 原則

  1. 先總後分：每頁先講 LEVEL1，再照畫面順序講每個 LEVEL2，不可跳過。
  2. 三句法講 LEVEL3：結論（扣回 LEVEL1）→ 實例（要有數字或情境）→ 意義（對聽眾有什麼用）。
  3. 小貓問聽眾心裡的問題：「這跟我有什麼關係？」，不問答案已寫在題目裡的假問題。
  4. 去 AI 味：不用驚嘆號，不用「讓我們、深入探討、賦能、打造」這類詞；用同事講話的口氣。
  5. 不加畫面沒有的數字：連自己算出來的數字也不行。

淺講還是深講？

淺講深講
每頁上限60 秒90 秒（加 --max-sec 90）
講到哪一層LEVEL1、LEVEL2再加每個 LEVEL2 的 1 個代表 LEVEL3，主 LEVEL2 多追問一輪
適合總覽、時間很少新手、要真的聽懂

想要成語典故：一頁一個、出處要查證、全稿不重複、講完立刻白話。AI 會自己審 3 輪，紀錄寫在 審查紀錄.md。

第 7 步：產生語音與嵌入

這一步通常由 AI 幫你下指令。知道在做什麼就好：

① 檢查對話稿錨點找不到、超過秒數都會報錯
python scripts/gen_duo_audio.py 對話稿.txt --deck 簡報.html --check --max-sec 90
② 產生語音改稿後重跑，只重做改過的段落
python scripts/gen_duo_audio.py 對話稿.txt --deck 簡報.html -o duo.json --proxy http://你的代理:port --say 唸法.txt --max-sec 90
③ 嵌回網頁可以重複執行，會先移除舊的
python scripts/embed_duo.py 簡報.html duo.json -o 輸出.html --bar tr --cards 成語卡.txt
  • 唸法.txt：英文縮寫怎麼唸，例如 kb_search=K B search。只影響聲音，字幕照原文。
  • 成語卡.txt：例如 狡兔三窟＝多準備幾條退路，字幕講到就跳出小卡。
  • 每頁 class 不是 slide 時，檢查用 --slide-class 名稱，嵌入用 --slide .名稱。
  • 實際語音常比估計多 8～15%。超過上限就刪機器人台詞的贅字，不要刪比喻。

第 8 步：驗證與上線

AI 會用瀏覽器自動測，你也可以自己點一遍：

  • ✅ 勾「自動連播」，能一路翻頁講到最後一頁。
  • ✅ 最長的那頁、最後一頁，人偶都站在對的重點旁。
  • ✅ 手機寬度：播放列不蓋到翻頁鈕。
  • ✅ 深色主題看得清楚。

上線後提醒聽眾：

  1. 按 Ctrl+F5 重新整理，才會載入新版。
  2. 用 Teams 分享時，要勾「包含電腦音效」，並分享整個畫面，不要只分享視窗。

完成標準：別人打開網址按 ▶，不用你在旁邊講，也能聽完整份教材。

# 雙人偶語音簡報（小貓問、機器人答）

這個 skill 把任何 HTML 簡報變成兩隻人偶一問一答的「會自己講的簡報」，最後輸出一個 HTML 檔，語音也包在裡面。

- **角色**：小貓負責提問（曉臻 `zh-TW-HsiaoChenNeural`），機器人負責回答（雲哲 `zh-TW-YunJheNeural`）。兩隻一直都在畫面上。
- **講話時**：小貓先出發，機器人晚半秒跟上，兩隻各走一條弧線，走到正在講的重點旁邊並排。講話的那隻頭上出現泡泡，另一隻轉頭看著它、點頭。待命時縮小、半透明站在角落。
- **自動補上 3 個幫助理解的措施**：
  1. 講到的區塊會打亮，其他地方稍微變暗。
  2. 下方顯示字幕，標出是誰在講。
  3. 每頁講完，跳出「一句話重點」卡。
- **播放方式**：按 ▶ 聽報告，或按 P 鍵；可勾選「自動連播」（跨頁一路播完）、「字幕」、「人偶」，語速鈕可切 1x／1.25x／1.5x。手動翻頁時，旁白會自動停止。
- **手機（寬度 ≤ 720px）**：人偶隱藏、只留字幕；播放列只剩 ▶ 和「自動連播」，不擋翻頁鈕。

## 步驟（照順序做；第 2、4、6 步是審核關卡，要等使用者同意才往下，不可因使用者沒空而自行跳過）

0. **先提工作規劃，問清楚 4 件事**（使用者沒空回時，自己決定並寫明假設）：
   - 直接取代原網頁，還是另做一個語音版？
   - 總時長多少？聽眾是誰（新手要多一句白話）？
   - 稿子要不要特別風格（例如成語、典故）？
1. **確認簡報結構**：
   - 執行 `python scripts/slides_text.py 簡報.html`，看看每頁的文字。
   - 如果每一頁的 class 不是 `slide`，加上 `--slide-class 名稱`。
   - 如果是 PPT，先轉成 HTML，每頁一個元素。
   - 列出每頁的標題層級（h2 是 LEVEL1，h3 是 LEVEL2，小標底下的數字、清單、表格列是 LEVEL3），檢查是不是「1 個 LEVEL1 + 3～4 個 LEVEL2」。
2. **擬教案 `教案.md`，給使用者審核**（站在資深教育人員的角度，先理解教材的編寫思路，再寫稿）：
   - **課程定位**：聽眾、先備知識、總時長、上完能做到什麼（2～3 個學習目標）。
   - **教學脈絡**：整份教材分成幾個章節、為什麼是這個順序（例如：引起動機 → 建立概念 → 實務經驗 → 動手應用），每章對應哪幾頁。
   - **每頁表格**：LEVEL1 重點、3～4 個 LEVEL2 重點、每個 LEVEL2 怎麼扣回 LEVEL1（關聯句）、深講時每個 LEVEL2 選哪個 LEVEL3 當代表（和選它的理由）、哪個是主 LEVEL2、成語典故、和上一頁怎麼銜接。
   - **教材調整建議**：頁面結構不符合「1 個 LEVEL1 + 3～4 個 LEVEL2」（LEVEL2 太少、太多、沒有標題）時，提出具體改法（加小標、合併分組、拆頁），說明理由。**使用者同意後才改網頁**，改完重新執行第 1 步。
3. **寫對話稿** `對話稿.txt`：依核准的教案寫，格式、時長、風格見 [dialogue-guide.md](dialogue-guide.md)。
   - 每頁先講 LEVEL1，再依畫面順序講每個 LEVEL2，每個 LEVEL2 都要扣回 LEVEL1，不可跳過任何一個 LEVEL2。
   - 淺講每頁不超過 60 秒，深講不超過 90 秒，依總時長算出每頁秒數。
   - 小貓先問，機器人用生活比喻回答。
   - 不能有 AI 腔。
   - 有指定風格時，自己審 3 輪再交稿，紀錄寫在 `審查紀錄.md`（第 1 輪要對照教案，確認每個 LEVEL2 都講到，深講時也確認每個代表 LEVEL3 都有數字或情境）。
4. **給使用者看稿，等他同意。**
   - 先跑 `python scripts/gen_duo_audio.py 對話稿.txt --deck 簡報.html --check [--max-sec 90]`，修到沒有「錯誤」，再把稿子、每頁秒數、預估總長給使用者看。
   - 使用者改過稿後，要重新檢查。
5. **產生語音**：
   ```
   python scripts/gen_duo_audio.py 對話稿.txt --deck 簡報.html -o duo.json --proxy http://你的代理:port [--say 唸法.txt] [--max-sec 90]
   ```
   - 語音會存到對話稿旁的 `duo_audio\` 當快取，改稿後重跑只會重做改過的段落。
   - 失敗的段落會自動等一下再補做；還是失敗就稍後重跑同一指令。
   - 有頁面實際超過上限（預設 60 秒，深講用 `--max-sec 90`）時，腳本會停下來：刪那頁的贅字再重跑。
6. **先試做前 5 頁，給使用者看過再做全部**：
   - 把前 5 頁另存成 `對話稿_試做.txt`，產生 `duo_P1-5.json`，嵌入後開給使用者看。
   - 同時自己審一遍，提出 5 個具體修改建議（例如播放列位置、手機版、人偶擋字、語速、新手看不懂的詞）。
   - 使用者同意後，才產生全部語音。
7. **嵌入**：
   ```
   python scripts/embed_duo.py 簡報.html duo.json -o 輸出.html --bar tr [--cards 成語卡.txt]
   ```
   - `--next "JS"`：簡報不是用 → 鍵翻頁時，給翻到下一頁的 JS。
   - `--active`：目前頁面的 class 不叫 `active` 時，用這個指定。
   - `--slide .page`：每頁的 class 不是 `slide` 時，用 CSS 選擇器指定（和第 1 步的 `--slide-class` 對應）。
   - **長頁面**（一頁比畫面高、要捲動）也能用：講到的重點在畫面外，會自動捲過去；換頁時回到頁首。錨點要挑「每段落各自的標題」，人偶才會一路往下帶。頁首有大圖時，第一句錨點選頁首標題，免得直接跳過大圖。
   - `--home`、`--bar`：改人偶待命角落、播放列位置（人偶會自動讓開同一角的播放列）。簡報下方有頁碼、翻頁鈕時，用 `--bar tr` 放右上角。
   - `--cards 成語卡.txt`：每行 `詞＝白話`，字幕講到該詞就在字幕上方跳出小卡（標點不影響比對）。
   - 可以重複執行，會先移除舊的嵌入。
   - 檔案大小約為「每分鐘語音 0.42 MB」：30 分鐘約 12.6 MB，GitHub Pages 可以放（單檔上限 100 MB），但開啟要等幾秒。
8. **驗證**（用 Playwright 開輸出檔，透過本機 http server）：
   - 按 ▶ 後，兩隻人偶會走到重點旁，泡泡、字幕、打亮都會出現。
   - 抽查幾頁，一定要包含最長的那頁和最後一頁。
   - Console 沒有 `[duo] 找不到錨點`。
   - 勾「自動連播」後，會自己翻頁接著講。快速測：`DUO.audio.muted = true`，再每 100 毫秒設一次 `DUO.audio.playbackRate = 16`，用 `DUO.page` 看目前頁。
   - 手機寬度（390px）：播放列不能蓋到翻頁鈕。
   - 深色主題也看一次。
9. **回報使用者**：
   - 輸出檔位置（或上線網址）與大小。
   - 全部自動連播要多久（`gen_duo_audio.py` 最後一行會印出來）。
   - 放上網站時，提醒按 Ctrl+F5 重新整理。
   - 提醒用 Teams 分享時，要勾「包含電腦音效」，並分享整個畫面，不要只分享視窗。

## 常見問題

| 狀況 | 處理 |
|------|------|
| edge-tts 連不上或卡住 | 公司網路一定要 `--proxy`，環境變數無效。腳本已內建 60 秒逾時和重試 6 次。 |
| `NoAudioReceived` 很多 | 被限流。腳本會自動等 30、60…秒補做；最後仍失敗就隔幾分鐘重跑，快取不會重做。 |
| 某頁實際超過上限秒數 | 估計常偏少 8～15%。刪那頁機器人台詞的贅字，重跑。 |
| 中文亂碼（cp950） | 腳本已改成 UTF-8 輸出；自己寫的 Python 要先設 `$env:PYTHONUTF8=1` |
| 錨點找不到 | 錨點必須是該頁上「看得到的文字」；圖片頁用 `家` 或 `@x,y` |
| 按 ▶ 沒聲音 | 瀏覽器要求先點一下頁面；從檔案開啟可以正常播放 |
| 人偶擋到內容 | 換一個更精準的錨點，或用 `@x,y` 指定位置 |
| 字幕被簡報自己的浮動按鈕蓋住 | 人偶、字幕、播放列的 z-index 已提高到 100000 以上；仍被蓋住時，檢查簡報按鈕的 z-index |

# 對話稿寫法

## 格式

```
【P5】重點：營發處負責把客戶的申辦，變成系統做得出來的訂單
貓｜簡單說｜營發處在忙什麼
營發處平常到底在忙什麼？
機｜=｜把申辦變成訂單
簡單說，客戶在門市辦的每一件事，最後都要變成一張訂單，系統才知道要做什麼。我們就是管這張訂單的人。
貓｜② 訂單處理｜一天有多少張
那一天大概會有幾張？
機｜=｜像物流中心
很多。你可以把它想成物流中心，包裹一直進來，我們要確保每一件都送到對的地方。
```

- `【P頁碼】重點：…`：一頁一個區塊。「重點」是這一頁講完後跳出的「一句話重點」卡，20 字左右。
- `角色｜錨點｜泡泡`：
  - 角色：`貓` 或 `機`。
  - 錨點有四種寫法：
    - 一段這頁上的原文（建議 2～10 字，而且只出現一次）
    - `=`：跟上一段同一個位置
    - `家`：回角落待命
    - `@橫%,直%`：例如 `@70,40`，給圖片頁用
  - 泡泡：頭上顯示的短句，15 字以內。
- 下一行起是要念出來的台詞，可以換行，會直接接在一起。台詞同時也是字幕。
- `#` 開頭的行是註解。

## 寫作原則

1. **先總後分，照教案走**：每頁第 1 輪講 LEVEL1（頁面大標題：這頁要解決什麼問題），接著每個 LEVEL2（小標題）各 1 輪，依畫面由上到下。
   - 每頁 4～5 輪：LEVEL1 一輪 + LEVEL2 三到四輪（深講再加主 LEVEL2 追問一輪）。每頁都由小貓先開口。
   - 每個 LEVEL2 的回答要扣回 LEVEL1，例如 LEVEL1 是「為什麼查很久」，LEVEL2「名詞不對應」就要講「這是查很久的第二個原因」。
   - 不可跳過畫面上的任何 LEVEL2。內容太多講不完時，回頭改教案（例如請使用者同意合併小標或拆頁），不要在稿子裡偷偷略過。
   - 最後一個 LEVEL2 講完，用半句話收回 LEVEL1，接上「一句話重點」卡。
2. **LEVEL3 不逐條唸，挑一個講透**（以一馭多）：LEVEL3 是 LEVEL2 底下的細項（數字、清單、表格列、步驟）。
   - **挑代表**：每個 LEVEL2 從它的 LEVEL3 裡挑 1 個代表。優先挑：有數字的、有真實情境的、有前後對比的、新手最容易誤會的。
   - **三句法**：機器人回答 LEVEL2 時照這個順序：
     1. 結論：一句話，扣回 LEVEL1。
     2. 實例：講那個代表 LEVEL3，要有數字或情境。
     3. 意義：對聽眾有什麼用，或一個生活比喻。
   - **其餘一句帶過**：說出共同點，例如「表上其他幾列病根相同：…」。不要逐條念，也不要說「請暫停細看」。
   - **錨點跟著走**：小貓的錨點放 LEVEL2 小標，機器人的錨點放代表 LEVEL3 的原文，打亮才會落在細項上，眼睛跟得上。
   - **主次分明**：每頁挑 1 個「主 LEVEL2」（最關鍵或最難懂的），小貓可以追問一輪（錨點用 `=`），往下多講一層「為什麼」或「其餘細項的共同點」。其他 LEVEL2 只講一輪。
   - **表格**：先講這張表在比什麼（欄位怎麼讀），再念一列當示範。
3. **小貓問的是聽眾心裡的問題**，例如：「這跟我有什麼關係？」「為什麼不能一套系統就好？」「這個英文縮寫是什麼？」。不要問答案已經寫在題目裡的假問題。
4. **機器人答「深入淺出」**：
   - 先講結論，一句話講完。
   - 接著用生活例子比喻，例如物流、餐廳點餐、搬家。
   - 最後拉回投影片上的字。
5. **長度**：淺講每頁台詞合計約 250 字（約 60 秒），深講約 330 字（約 85 秒）。每段 70 字以內，方便看字幕。
6. **錨點要對**：
   - 每一輪問答指向這頁的一個重點區塊，依投影片由上到下的順序走。
   - 錨點文字從 `slides_text.py` 的輸出直接複製。
7. **去 AI 味**：
   - 不用驚嘆號。
   - 不用以下說法：讓我們、一起來、深入探討、總而言之、值得一提、賦能、助力、打造、旨在、至關重要、無縫。
   - 用同事之間講話的口氣，可以用「其實」「說白了」「你可以想成」。
8. **不加投影片沒有的數字或承諾**。自己算出來的數字也不行（例如「一天看十支要看一年半」）。不確定的內容就不要講。
9. **專有名詞的唸法**寫在唸法檔，一行一個，格式是 `畫面字=唸法`，例如：
   ```
   mORDER=M Order
   TMF622=TMF 六二二
   ```
   這只影響聲音，字幕仍顯示原文。
10. **聽眾是新手時**：每個專有名詞、成語第一次出現，就緊接一句白話解釋。寧可多講一句，也不要讓人卡住。

## 時長怎麼抓

- **先選講解深度**（工作規劃時問使用者）：
  - **淺講（每頁 ≤ 60 秒）**：只講 LEVEL1、LEVEL2，每輪約 11～12 秒。適合總覽、時間很少時。
  - **深講（每頁 ≤ 90 秒，加 `--max-sec 90`）**：LEVEL2 用三句法帶 1 個 LEVEL3，每輪約 18～20 秒，外加主 LEVEL2 追問一輪。總長約為淺講的 1.45 倍。
- **先定總長，再算每頁秒數**：每頁秒數 ≈ 總分鐘 × 60 ÷ 頁數 − 8（8 秒是重點卡加翻頁）。例如 30 分鐘、29 頁，每頁約 52～55 秒。
- **估計會偏少**：實際語音約為估計 × 1.08，個別頁會多到 15%。`--check` 估計超過上限前 5 秒（例如 55 或 85 秒）會提醒，最好留 3～5 秒餘裕。
- **超過上限時**：刪機器人台詞裡的贅字（例如「一張白紙」改「白紙」、「最後貼進」改「再貼進」），不要刪掉比喻或解釋。重跑時只會重做改過的段落。

## 文學風格（使用者要求「成語、典故」時才用）

1. **一頁一個主成語或典故**，放進「重點」，例如「工欲善其事，必先利其器」。
2. **出處要查證**：講典故時說出人物和故事，例如「宋朝文與可畫竹前，心中早有竹子的樣子」。不確定出處的就不要講故事，只用成語。
3. **全稿不重複**：同一個成語只用一次。寫完列一張「每頁重點」表檢查。
4. **意思要貼切**：意思不合或容易聯想到別的事情的成語要換掉（例如「星星之火」）。
5. **講完立刻白話**：例如「量體裁衣，就是看對象調整內容」。
6. **做成語卡** `成語卡.txt`，嵌入時用 `--cards`：
   ```
   # 一行一個：詞＝白話（15 字左右）
   言必有據＝說話要有根據
   刻舟求劍＝拿舊方法套新情況
   ```
   只收新手可能看不懂的詞；大家都懂的（例如「與時俱進」）不用收。卡片的詞必須跟台詞一字不差（標點可不同）。
7. **自己審 3 輪再給使用者看**，紀錄寫在 `審查紀錄.md`：
   - 第 1 輪：加入成語典故，錨點和重點不動。
   - 第 2 輪：查出處、去重複、補足或刪減秒數。
   - 第 3 輪：替新手補白話，拆開太長的字幕。

"""列出 HTML 簡報每一頁的文字，供撰寫對話稿與檢查錨點。

用法：python slides_text.py deck.html [--slide-class slide]
"""
import argparse, re, sys
from html.parser import HTMLParser

VOID = {'area', 'base', 'br', 'col', 'embed', 'hr', 'img', 'input', 'link', 'meta', 'source', 'track', 'wbr'}
BLOCK = {'p', 'div', 'li', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6', 'tr', 'td', 'th', 'section', 'br', 'dt', 'dd', 'figcaption', 'text'}


class _P(HTMLParser):
    def __init__(self, cls):
        super().__init__(convert_charrefs=True)
        self.cls, self.depth, self.start, self.skip = cls, 0, None, 0
        self.pages, self.buf = [], []

    def handle_starttag(self, tag, attrs):
        if tag in VOID:
            if self.start is not None and tag in BLOCK: self.buf.append('\n')
            return
        self.depth += 1
        if tag in ('script', 'style'): self.skip += 1
        c = (dict(attrs).get('class') or '').split()
        if self.start is None and self.cls in c:
            self.start, self.buf = self.depth, []
        elif self.start is not None and tag in BLOCK:
            self.buf.append('\n')

    def handle_endtag(self, tag):
        if tag in VOID: return
        if tag in ('script', 'style') and self.skip: self.skip -= 1
        if self.start is not None and self.depth == self.start:
            self.pages.append(''.join(self.buf)); self.start = None
        elif self.start is not None and tag in BLOCK:
            self.buf.append('\n')
        self.depth -= 1

    def handle_data(self, d):
        if self.start is not None and not self.skip: self.buf.append(d)


def slide_texts(html_text, cls='slide'):
    """回傳每頁文字（保留換行），頁碼＝索引＋1。"""
    p = _P(cls); p.feed(html_text); p.close()
    out = []
    for t in p.pages:
        lines = [' '.join(x.split()) for x in t.split('\n')]
        out.append('\n'.join(x for x in lines if x))
    return out


norm = lambda s: re.sub(r'\s+', '', s or '')

if __name__ == '__main__':
    sys.stdout.reconfigure(encoding='utf-8')
    ap = argparse.ArgumentParser()
    ap.add_argument('deck'); ap.add_argument('--slide-class', default='slide')
    a = ap.parse_args()
    pages = slide_texts(open(a.deck, encoding='utf-8-sig').read(), a.slide_class)
    if not pages: sys.exit(f'找不到 class="{a.slide_class}" 的頁面，請用 --slide-class 指定')
    for i, t in enumerate(pages, 1):
        print(f'【P{i}】' + ('（沒有文字，可能是圖片頁）' if not t else ''))
        if t: print(t)
        print()

def parse(src):
    pages, errs = {}, []
    for blk in re.split(r'\n(?=【P\d+】)', '\n' + src.replace('\r', '')):
        m = re.match(r'【P(\d+)】(.*)', blk.strip())
        if not m: continue
        n, head = int(m.group(1)), m.group(2).strip()
        km = re.match(r'重點[:：]\s*(.+)', head)
        if not km: errs.append(f'P{n}：標題列要寫「【P{n}】重點：一句話重點」')
        segs, prev = [], None
        for ln in blk.strip().split('\n')[1:]:
            ln = ln.strip()
            if not ln or ln.startswith('#'): continue
            h = re.match(r'^([^｜|]+)[｜|]([^｜|]*)[｜|](.*)$', ln)
            if h:
                who = WHO.get(h.group(1).strip())
                if not who: errs.append(f'P{n}：角色「{h.group(1)}」要寫 貓 或 機'); who = 'robot'
                a = h.group(2).strip()
                if a == '=':
                    if prev is None: errs.append(f'P{n}：第一段不能用「=」'); at = {'home': 1}
                    else: at = dict(prev)
                elif a in ('', '家', 'home'): at = {'home': 1}
                elif a.startswith('@'):
                    try: x, y = [float(v) for v in a[1:].split(',')]; at = {'p': [x, y]}
                    except ValueError: errs.append(f'P{n}：位置「{a}」要寫成 @橫%,直%（例：@70,40）'); at = {'home': 1}
                else: at = {'q': a}
                prev = at
                segs.append({'who': who, 'at': at, 'tip': h.group(3).strip(), 't': ''})
            elif segs: segs[-1]['t'] += ln
            else: errs.append(f'P{n}：台詞前面要先有「角色｜錨點｜泡泡」')
        for s in segs:
            if not s['t']: errs.append(f'P{n}：「{s["tip"]}」這段沒有台詞')
        pages[n] = {'key': km.group(1).strip() if km else '', 'segs': segs}
    return pages, errs


def lint(pages, deck_pages, max_sec=60):
    errs, warns = [], []
    for n, p in sorted(pages.items()):
        if not p['segs']: errs.append(f'P{n}：沒有任何對話'); continue
        if p['segs'][0]['who'] != 'cat': warns.append(f'P{n}：建議由小貓先問')
        if deck_pages is not None:
            if n > len(deck_pages): errs.append(f'P{n}：簡報只有 {len(deck_pages)} 頁'); continue
            txt = norm(deck_pages[n - 1])
            for s in p['segs']:
                q = s['at'].get('q')
                if q and norm(q) not in txt: errs.append(f'P{n}：錨點「{q}」不在這頁的文字裡（圖片頁請用 家 或 @x,y）')
        for s in p['segs']:
            t = s['t']
            if len(t) > 70: warns.append(f'P{n}：「{t[:12]}…」{len(t)} 字，字幕太長，建議拆段')
            if re.search(r'[！!]', t + s['tip']): warns.append(f'P{n}：「{t[:12]}…」有驚嘆號')
            for w in AI_TONE:
                if w in t or w in s['tip']: warns.append(f'P{n}：「{w}」口氣太像 AI，換個說法')
        est = sum(len(re.sub(r'\s', '', s['t'])) / CPS + GAP for s in p['segs'])
        p['est'] = est
        if est > max_sec: errs.append(f'P{n}：估計 {est:.0f} 秒，超過 {max_sec} 秒，請刪字')
        elif est > max_sec - 5: warns.append(f'P{n}：估計 {est:.0f} 秒，實際語音常比估計多 8～15%，可能超過 {max_sec} 秒')
    return errs, warns


def load_say(path):
    rules = list(BASE_SAY)
    if path:
        for ln in open(path, encoding='utf-8-sig'):
            if '=' in ln and not ln.startswith('#'):
                a, b = ln.rstrip('\n').split('=', 1); rules.insert(0, (a, b))
    rules.sort(key=lambda r: -len(r[0]))
    return rules


async def tts(text, voice, rate, proxy, cache, sem):
    import edge_tts
    f = os.path.join(cache, hashlib.sha1(f'{voice}|{rate}|{text}'.encode()).hexdigest()[:16] + '.mp3')
    if os.path.exists(f): return f
    async with sem:
        async def one():
            b = bytearray()
            async for ch in edge_tts.Communicate(text, voice, rate=rate, proxy=proxy).stream():
                if ch['type'] == 'audio': b += ch['data']
            return b
        for k in range(6):
            try:
                b = await asyncio.wait_for(one(), 60)      # 偶爾會卡住，要有逾時
                if b:
                    open(f, 'wb').write(b); print('  ok', voice[6:-6], text[:14], flush=True); return f
            except Exception as e:
                print('  retry', k + 1, type(e).__name__, flush=True)
            await asyncio.sleep(3)
    print('  失敗，稍後整批重試：', text[:20], flush=True)
    return None


async def build(pages, a):
    rules, cache = load_say(a.say), a.cache
    os.makedirs(cache, exist_ok=True)
    sem = asyncio.Semaphore(4)
    def spoken(t):
        for x, y in rules: t = t.replace(x, y)
        return t
    order = [(n, s) for n in sorted(pages) for s in pages[n]['segs']]
    print('語音段數', len(order), flush=True)
    job = lambda s: tts(spoken(s['t']), VOICE[s['who']], RATE[s['who']], a.proxy, cache, sem)
    files = await asyncio.gather(*[job(s) for _, s in order])
    for r in range(5):                                   # edge-tts 常限流（NoAudioReceived），等一下再補做失敗的段落
        bad = [i for i, f in enumerate(files) if not f]
        if not bad: break
        print(f'有 {len(bad)} 段失敗，{30 * (r + 1)} 秒後第 {r + 1} 次補做', flush=True)
        await asyncio.sleep(30 * (r + 1))
        for i, f in zip(bad, await asyncio.gather(*[job(order[i][1]) for i in bad])): files[i] = f
    if not all(files): sys.exit('仍有語音段落失敗；已完成的都在快取裡，稍後重跑同一指令即可')
    sec = lambda f: os.path.getsize(f) * 8 / 48000                         # edge-tts 預設 48kbps
    out, tot, worst = {}, 0, 0
    for (n, s), f in zip(order, files):
        p = out.setdefault(str(n), {'key': pages[n]['key'], 'segs': [], 'sec': 0})
        p['segs'].append({'who': s['who'], 't': s['t'], 'tip': s['tip'], 'at': s['at'], 'a': base64.b64encode(open(f, 'rb').read()).decode()})
        p['sec'] += sec(f) + GAP
    for n, p in out.items():
        worst = max(worst, p['sec']); tot += p['sec'] + KEY_SEC + TURN_SEC
        print(f'P{n}: {p["sec"]:.1f} 秒' + (f'  ← 超過 {a.max_sec} 秒' if p['sec'] > a.max_sec else ''))
        p['sec'] = round(p['sec'], 1)
    json.dump({'pages': out}, open(a.out, 'w', encoding='utf-8'), ensure_ascii=False)
    print(f'輸出 {a.out}（{os.path.getsize(a.out) / 1e6:.1f} MB）；自動連播全部約 {int(tot // 60)} 分 {int(tot % 60)} 秒')
    if worst > a.max_sec: sys.exit(f'有頁面超過 {a.max_sec} 秒，請刪減台詞後重跑')

自我檢核：7 題

1. 為什麼要先擬教案，再寫對話稿？

先懂教材的思路。知道每頁的 LEVEL1 和 LEVEL2 怎麼連，稿子才會先總後分，不會東一句、西一句。

2. 某頁有 6 個 LEVEL2，講不完，怎麼辦？

在教案階段提出來。建議合併小標或拆頁，你同意後才改網頁。不可以在稿子裡偷偷略過。

3. 錨點寫「→ 答錯了！」卻找不到，為什麼？

符號容易對不上。錨點要挑那頁看得到、只出現一次的字，改成「答錯了」就好。

4. 淺講和深講差在哪？

差在 LEVEL3。淺講每頁 60 秒，只講 LEVEL1、LEVEL2；深講每頁 90 秒，每個 LEVEL2 再挑 1 個 LEVEL3 用三句法講透。

5. 深講版某頁實際 94 秒，怎麼辦？

刪機器人台詞的贅字，再重跑。不要刪比喻和解釋。重跑只會重做改過的段落。

6. 稿子可以說「一天看十支，要看一年半」嗎？

不行。這是自己算出來的數字，畫面上沒有。不確定的內容就不要講。

7. 用 Teams 分享時，大家聽不到聲音？

勾「包含電腦音效」，並分享整個畫面。只分享視窗時，聲音常常傳不出去。

重點回顧

  • duo-narrated-deck 把 HTML 教材變成小貓問、機器人答的語音導讀，語音包在同一個檔案裡。
  • 流程 10 步，3 道審核關卡：教案、對話稿、前 5 頁試做，都要你同意才往下。
  • 先擬教案：照教材思路，每頁 1 個 LEVEL1 + 3～4 個 LEVEL2。
  • 寫稿先總後分；深講用三句法帶 1 個 LEVEL3；不加畫面沒有的數字。
  • 上線後提醒 Ctrl+F5；Teams 分享要含電腦音效、分享整個畫面。
